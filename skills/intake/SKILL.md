# Common Rules intake

Announce: **Common Rules skill: intake — relating this request to tracked
delivery.** Classify the message as research, feature, defect, decision or
question. Locate the workspace hub and owning repository. Record the verbatim
ask in the owning proposal ledger; connect it to an existing user-deliverable
feature or create a proposal candidate. Do not silently turn an idea into
accepted scope.
