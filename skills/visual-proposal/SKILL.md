# Visual proposal

Say: **Common Rules skill: visual-proposal — turning this decision into a visual
artifact.** Use diagrams, cards, short labels and progressive disclosure; the
page must be understandable on a phone without reading long prose. Keep numbered
decisions stable, record each sponsor answer verbatim, and iterate the same file
until accepted. Acceptance creates requirements and design work; it is not
implementation evidence. Preserve the earlier visual companion content when
consolidating proposals.
