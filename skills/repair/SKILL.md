# Repair

Announce the failed rule that selected this skill. Reproduce the finding first,
make the narrowest correction in the owning repository, update requirements or
evidence when behaviour changed, and re-run the same gate. Never waive a broken
link by deleting traceability; use an owner-reviewed refusal when no change is
the correct outcome.
