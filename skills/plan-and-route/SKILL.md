# Plan and route

Make the active skill and reason visible. Confirm proposal acceptance. Create
numbered, testable requirements; then a design naming repository ownership,
files, tests, risk and cross-repository impact. Populate traceability rows and
feature lifecycle parts. Work does not start until requirements and design are
reviewable.
