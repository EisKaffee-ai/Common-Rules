## The one-minute model

Emberline keeps a durable project record beside the conversations that produce
the work. A fresh session uses **warm-up** to load that record; a running
session uses **reheat** to catch up on changes. Proposals turn decisions into
tracked work, and the generated tracker makes the current state inspectable.

The record supports the agents. It does not replace tests, human acceptance,
or the source code.
